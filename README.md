# Winly 个人工作区

这是用于整理个人项目、资料和任务输出的工作区。根目录保存通用说明及明确指定的临时文件，各项目的代码、文档和专用规则分别放在对应子目录中。

## 工作区规则

- [`AGENTS.md`](./AGENTS.md) 是整个工作区的通用指令。
- 子目录存在 `AGENTS.md` 时，处理该目录内容还须遵循对应的项目专用规则。
- 开始修改前应先核对目标文件、操作范围和相关指令，完成后执行与变更直接相关的最小验证。
- 临时输入和输出放在工作区根目录，并使用 `_tmp_` 前缀或其他可明确识别用途的名称。

## 目录结构

```text
Winly-sync/
├─ AGENTS.md
├─ README.md
└─ isometric-web-prototype/
```

各项目的具体说明、入口和维护规则由对应项目目录自行记录，根目录 README 不重复展开。

## 维护约定

- 不混用不同项目或不同资料类型的文件。
- 尽量保持已有文件的结构、编码、排版和命名风格。
- 不随意删除、移动、重命名或覆盖已有资料。
- 新增项目时，只需在顶层目录结构中登记项目目录。
