# KeystoneLoot Mists

面向《魔兽世界：熊猫人之谜》经典服 5.5.4 的“决战奥格瑞玛”独立掉落浏览插件。它采用地下城手册的实时数据，复刻 KeystoneLoot 的核心浏览、筛选、收藏和进本提醒体验，不依赖正式服插件。

## 已实现

- 仅显示“决战奥格瑞玛”的 14 个首领、共享及小怪掉落
- 天神、随机团队、10/25 人普通、10/25 人英雄、弹性团队难度
- 职业、专精与装备部位筛选
- 当前角色独立收藏
- “可选 / 必需 / BIS / 幻化”四级收藏标记
- 左键选择掉落后按职业与专精显示队友同部位装备、升级进度、实际装等及同款拥有状态
- 以目标装备装等比较队友当前部位：低于目标显示“有需求”，高于目标显示“无需求”，相等时区分“已装备”和“同等级”
- T16 套装券按真实兑换职业组比较，支持贼/法/德/DK 等组内竞争提示
- 小地图右键打开队伍套装窗口，显示玩家自己、队友及曾组队同公会成员的五个套装部位、更新时间、实际装等和 T16/T15/T14 组合
- 进入对应副本时显示收藏掉落提醒
- 小地图按钮和聊天命令

## 安装

将整个 `KeystoneLoot-Mists` 文件夹复制到：

`World of Warcraft/_classic_/Interface/AddOns/`

最终目录中应直接看到 `KeystoneLoot-Mists.toc`，不要多套一层文件夹。进入游戏后在插件列表中启用“KeystoneLoot 熊猫人版”。

## 操作

- `/ksl`、`/keyloot` 或 `/pandarialoot`：打开/关闭主界面
- 左键物品：打开该物品的队伍装备需求面板
- 右键物品：打开“可选 / 必需 / BIS / 幻化 / 取消”收藏菜单
- Shift+左键物品：发送物品链接到聊天框
- 悬浮掉落总览物品：显示物品详情和玩家当前同部位装备对比
- 掉落总览中的可装备物品统一按升级 `2/2` 计算，图标只标出升级后的实际装等，物品详情及竞争比较使用同一升级状态
- 每次打开掉落总览：默认切换到“全部部位 + 英雄”，保留当前职业和专精选择
- 队伍装备需求面板：紧贴套装侧栏下方，不显示额外标题但保留目标装备卡片；目标装备详情直接常驻显示，详情框右下角与竞争面板右上角重合。竞争者按“有需求、无需求、未读取”分类列出姓名、状态和当前装备图标；已装备、同等级及装等更高归入无需求，正在读取及尚未读取归入未读取，观察完成后即时移动到对应分类
- 小地图图标左键：打开掉落总览
- 小地图图标右键：打开/关闭队伍套装窗口
- `/ksl test`：无需组队，打开队伍装备需求预览面板；再次输入可关闭
- `/ksl reminder`：切换进本提醒
- `/ksl minimap`：切换小地图按钮
- `/ksl reset`：重置主窗口位置

## 数据与兼容性

插件通过熊猫人客户端的 `EJ_*` 与 `C_EncounterJournal` 接口读取决战奥格瑞玛（Journal ID 369）数据，不复制 KeystoneLoot 正式服数据库。当前难度没有掉落的首领会显示为“无掉落”。

加入队伍后，插件会在后台逐个观察队友，未成功的成员会间隔重试，直到本次组队成员全部读取成功；完成后停止自动更新。打开队伍套装窗口或左键打开装备竞争面板时，会再对当前相关成员尝试刷新一轮；无法观察时直接显示上次共享缓存，不会把失败误判为没有需求，也不会因缓存时间较长而隐藏旧结果。两个面板共用同一份成员装备快照。观察只能读取角色当前穿戴，无法知道对方背包、银行或未装备的套装；队友无需安装本插件。

队伍套装窗口将玩家自己固定显示在第一行，再按队伍顺序列出其他成员；曾经成功读取过、且与玩家当前同公会的历史队友显示在下方独立区域，当前队伍与公会历史按角色 GUID 去重。姓名下方显示最近更新时间。头、肩、胸、手、腿五个部位中，T16 使用绿色边框，T15/T14 使用橙色边框，其他装备使用红色边框；组合文案按 `3T16`、`2T16+2T15` 等格式显示，没有套装部件时显示“散件”。装备链接保留升级信息，界面显示升级后的实际装等，并在可读取时标出升级进度。竞争目标装备使用独立的常驻详情框；竞争者及套装窗口中的装备图标悬浮提示只显示该装备本身，不附加玩家自身装备对比，并显示在竞争面板图层之上。

这是首个可测试版本。首次进入游戏后，请重点检查天神难度、职业/专精过滤、各团队难度以及进入决战奥格瑞玛后的提醒。
