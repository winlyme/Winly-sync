## Boss2 下沉房间与楼梯高度

工作簿网格、碰撞和固定坐标保持二维整数，不把视觉高度写进寻路数据。`data.js` 为围栏内 14 个地面格记录 `elevation: 18`，为围栏外侧紧邻的 28 个 `0` 楼梯格记录 `elevation: 9`；数值表示相对同一网格投影向屏幕下方的像素偏移：

- 普通大厅地面：`0px`。
- 外圈弧形下行楼梯：`+9px`。
- 围栏内部下沉地面：`+18px`。

`render.js` 在地面、物件、蕾琳、Boss、阴影、投射物终点和深度排序共用的 `gridToScreen()` 基础上插值该高度，因此角色下楼时不会瞬移；Boss2、其地面阴影、实际受击目标和投射物目标共享低层接地点。T-20260804-009 已有的炉心巨像主体相对接地点上移 24 屏幕像素规则继续保留，阴影仍留在低层地面且只绘制一层。围栏坐标与普通地面齐平，形成下沉房间的边界；相邻高度差由地面侧立面表现。

## 正式资料图更新

在项目根目录运行：

```text
node art/maps/generate-graystone-trial-overview.js
```

生成器会先创建当前 `Game.Data.createWorld()`，执行 `Game.Data.validateDungeon()`，再通过实际寻路器重建 SVG 中的地图、可见阻挡、Boss/交战位、折返路线和数量说明。PNG 是该 SVG 按 2400×4300 像素、72 DPI 本地栅格化的同源产物；重新生成 SVG 后应同步重建 PNG，并检查两者尺寸、图例、路线及下沉房间关系。
