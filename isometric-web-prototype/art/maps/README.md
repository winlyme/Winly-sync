# 灰岩试炼俯视资料图

- 主文件：`graystone-trial-overview.png`（3700 × 3700 px）。
- 矢量源：`graystone-trial-overview.svg`（3200 × 3700 SVG 画布）。
- 一次性数据生成器：`generate-graystone-trial-overview.js`。
- 本资料不在游戏加载链中，不会改动主页面、存档或运行时依赖。

## 数据依据

生成器直接加载项目根目录的 `core.js`、`data.js` 与 `world.js`，调用 `Game.Data.createWorld(960, 620)` 后读取同一份 `dungeon.map`、`props`、`entry`、`routeNodes` 和交战数据；生成前会调用 `Game.Data.validateDungeon(dungeon)`，实际路线调用运行时同一个 `Game.World.findPreferredPathResult()`。

地图网格尺寸为 `70 × 88`。图中采用标准俯视坐标：上北（`-Y`）、右东（`+X`）、下南（`+Y`）、左西（`-X`）。黄色为运行时偏好主路线，蓝色为击败第 2 名首领后返回主走廊分叉的合法折返路线。

本轮导航节点以真实连接位置为准：北侧折线路径 `zigzag_route` 位于 `(31, 55)`，主走廊分叉 `main_fork` 位于 `(42, 27)`。前者让角色从该节点连续向北进入 Boss 1 交战位；后者位于内部楼梯与横向走廊的交点，进入 Boss 2 时直接向东，击败后返回同一分叉再向西进入图书馆。

南侧入口由 `(8, 85)`、`(10, 85)` 两段阻挡石墙和中间 `(9, 85)` 的非阻挡实体门洞组成；门内出生点仍为 `(9, 82)`。门洞、墙体和入口标记均直接读取 `dungeon.props` 与 `dungeon.entry`，不含传送门或发光光幕；入口到首个路线节点仍使用原有主路线。

## 偏好寻路与对比口径

运行时先用普通 BFS 得到硬性最短步数，再在每段最多增加 2 步的预算内，以成员当前方向、转弯、正交/斜角阻挡和两格范围净空做确定性比较。目标格与末端邻近范围降低净空惩罚，确保门口、楼梯、路线节点和固定交战位仍是硬目标。同一输入重复规划会生成完全相同的路径。

- 步数：路径数组长度，不含该段起点。
- 转弯：相邻移动向量变化计 1；每段首步偏离继承方向也计 1。Boss 战后的固定面向不单独计数，但下一段首步会相对该方向比较。
- 贴墙步：进入格至少有一个正交相邻位置为不存在地形、地图外、`blocks:true` 物件或当前存活 Boss 时计 1；固定交战位邻接 Boss 属于不可避免的硬目标。

当前完整副本偏好路线为 **170 步、25 次转弯、19 个贴墙步**；普通最短路为 **170 步、32 次转弯、45 个贴墙步**。偏好路线没有增加步数，转弯减少 7 次，贴墙步减少 26 个。

| 路段 | 偏好：步 / 转 / 贴墙 | 普通：步 / 转 / 贴墙 |
| --- | --- | --- |
| 入口 → 入口节点 | 16 / 1 / 2 | 16 / 1 / 2 |
| 入口节点 → 训练场 | 25 / 5 / 3 | 25 / 6 / 9 |
| 训练场 → 折线路径 | 14 / 2 / 0 | 14 / 4 / 5 |
| 折线路径 → Boss 1 | 3 / 1 / 1 | 3 / 0 / 1 |
| Boss 1 → 楼梯 | 10 / 1 / 0 | 10 / 2 / 0 |
| 楼梯 → 武器库 | 6 / 1 / 1 | 6 / 2 / 1 |
| 武器库 → 内部楼梯 | 23 / 6 / 5 | 23 / 6 / 17 |
| 内部楼梯 → 分叉 | 5 / 0 / 0 | 5 / 0 / 0 |
| 分叉 → Boss 2 | 15 / 1 / 1 | 15 / 1 / 1 |
| Boss 2 → 分叉折返 | 15 / 1 / 0 | 15 / 1 / 0 |
| 分叉 → 图书馆转点 | 12 / 0 / 0 | 12 / 0 / 0 |

| 图书馆 → Boss 3 | 9 / 2 / 2 | 9 / 4 / 3 |

本轮资料图额外标出三组会改变实际寻路的可见阻挡物：

- 训练场的橙色标记：成组训练假人与兵器架，形成训练阵列间的绕行动线。
- 步兵武器库的红褐色标记：箱柜与储藏架，形成货架之间的仓储通道。
- 图书馆长廊的紫色标记：成排高书架，形成书架之间的阅读过道。

三组阻挡物全部来自 `dungeon.props`，并带有 `blocks: true` 与对应的 `routeObstacleGroup`。这里统一使用相同的偏好寻路逻辑，只过滤指定障碍数据：完整路线为 170 步；过滤三组障碍后为 150 步，增加 20 步，增幅约 13.3%。分区对比为：训练场相关路段 39 / 33 步（+6），武器库相关路段 29 / 21 步（+8），图书馆相关路段 26 / 20 步（+6）。

## 场景细节与比例

运行时仍由 Canvas 程序化绘制，不使用本资料图作为贴图。当前数据包含南侧实体石墙门洞、入口残柱与旧路标、训练场陈设、守门厅门框与火盆、武器库箱柜/储藏架/熄灭锻炉、主走廊边缘柱、圆厅外圈陈列、图书馆书桌/书页/烛台，以及最终厅黑曜石基座与秘法环纹。

以蕾琳站立高度 64px 为标尺，营地成熟树约 126～143px，帐篷约 81px；副本门框约 92px，书架与储藏架约 82px，高柱约 77～81px，训练假人约 60～63px，兵器架约 55～56px，箱柜/火盆/低矮杂物约 24～48px。碰撞仍只占物件所在的地面格，树冠和书架顶部的视觉外扩不扩大地面阻挡。

## 更新方式

在项目根目录运行：

```text
node art/maps/generate-graystone-trial-overview.js
```

该命令重建 SVG；当前 PNG 为该 SVG 的高清本地栅格化产物。地图数据、首领坐标、路线或交战位变更后，应先重新生成 SVG，再重新栅格化 PNG 并核对像素尺寸与图例。
